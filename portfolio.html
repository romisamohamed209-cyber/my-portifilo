DataCo Smart Supply Chain Analytics

Graduation project for the NTI Advanced Data Analysis Track — an end-to-end data pipeline and predictive analytics build on a Medallion architecture (Bronze → Silver → Gold), covering the full lifecycle from raw data to BI to a deployed ML model.

Problem: A 180,519-row, 53-column supply chain dataset had no governed pipeline — no cleaning, no schema, and no way to flag late-delivery risk before an order shipped.

Goal: Build a production-style pipeline that ingests, cleans and models the data into a star schema, surfaces it in a business-ready dashboard, and predicts late delivery risk in real time.
